Interpres

Open source

Interpres works with OS Live Captions (not a stand-alone speech engine). Native Win32 and AppKit UIs, opt-in dated session transcripts, light/dark/system theme, and a strict zero crates.io Rust core. Portable Mac and Windows builds; no subscription or cloud account.

AgentVideoParse

Open source

Agents read stills well but struggle with video. AgentVideoParse rejects clips over 30 seconds on purpose, samples agent-friendly JPEGs, and writes a manifest. Native macOS (SwiftUI + AVFoundation) and Windows (WPF) apps with a unified shell — no Python required for end users. Fully local, MIT.

AgentGifParse

Open source

Sibling to AgentVideoParse for GIF-only workflows. Hard 30s reject, 2 fps sampling (max 60 stills), agent-friendly JPEGs, and a manifest. Useful when short loops come from UI bugs or generative tools (Imagine-class / Seedance-style GIF and clip exports). Native macOS (SwiftUI + ImageIO) and Windows (WPF + WIC) apps; fully local, MIT.
